Source: fenghaolin/HanguData
Source file: Data.csv

This repository copy is included for validation and research use under the source license. Preserve attribution and the original license terms when redistributing the dataset.

Dataset scope: de-identified outpatient consultation records used for hospital scheduling/service-time research. This real-world dataset is used here only for tasks whose target can be supported by observed fields. It is not treated as ground truth for the optimal appointment/doctor schedule because it does not encode an independently adjudicated optimal scheduling policy.
